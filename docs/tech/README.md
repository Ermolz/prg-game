# Технології проєкту Dots and Boxes

У цій папці описані технології та мови програмування, які використовуються в проєкті: навіщо вони потрібні і де саме застосовуються (зі посиланнями на код).

| Мова / платформа | Призначення |
|------------------|-------------|
| [TypeScript / JavaScript](typescript.md) | Десктопний інтерфейс (Electron), веб-інтерфейс (React), збірка (Vite), скрипти |
| [C#](csharp.md) | Один із рушіїв гри (CLI), ядро логіки |
| [Java](java.md) | Ще один рушій гри (CLI), тести |
| [Python](python.md) | Черговий рушій гри (CLI), модулі логіки |
| [Prolog](prolog.md) | Рушій гри на SWI-Prolog (CLI та логіка) |

**Спільний протокол** (усі рушії): [JSON-RPC по stdin/stdout, методи, формат state/edge/box](protocol.md).

Усі посилання в документах відносні до кореня репозиторію (`game/`).
